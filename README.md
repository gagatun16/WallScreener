# WallScreener

Скринер крупных заявок в стакане криптофьючерсов. Следит за большими бидами и асками на шести биржах, держит «стены» (плотности), пока они живут в стакане, и записывает, как они закрылись: разъели сделками, сняли или был отскок.

Сайт: http://127.0.0.1:5000  
Биржи: Binance, Bybit, OKX, Bitget, MEXC, BingX.

Скринер информационный: заявки не выставляет.

## Что умеет

- Отбирает ликвидные и волатильные USDT-пары по часовому обороту и True Range %.
- Ищет стены в стакане: размер ≥ 50 000 USDT и ≥ 3× медианы объёма 5-минутных свечей в USDT.
- Раз в минуту проверяет живые стены: ещё в стакане, касание, разбор лентой сделок или исчезновение.
- Показывает на сайте стены с жизнью ≥ 5 минут, контекст BTC, расстояние до цены и мини-графики.
- Пишет закрытые стены в локальный журнал: отскок / пробой / снятие и снимки графиков.

## Стек

- Python 3, Flask, aiohttp
- asyncio-сканеры в одном процессе с интерфейсом
- pandas, matplotlib, mplfinance для графиков журнала

## Устройство

```
app.py                 сайт Flask, REST API и фоновый поток сканера
main.py                список сканеров бирж
scanner_manager.py     раз в час монеты → раз в 5 минут стаканы → раз в минуту стены
config/params.py       пороги
exchanges/<биржа>/     символы, стакан, плотности по площадке
utils/                 фильтры, журнал, графики, контекст BTC, алерты в Telegram
templates/index.html   живая таблица и журнал
```

Ключи API в git не попадают. Нужно скопировать example-файлы и заполнить их локально.

## Запуск

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\activate
pip install -r requirements.txt
copy config\api_keys.example.py config\api_keys.py
copy config\api_tg_keys.example.py config\api_tg_keys.py
python app.py
```

Linux / macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
cp config/api_keys.example.py config/api_keys.py
cp config/api_tg_keys.example.py config/api_tg_keys.py
python app.py
```

Открыть http://127.0.0.1:5000

В `config/api_keys.py` и `config/api_tg_keys.py` подставить свои ключи. Telegram нужен только для алертов: без бота сканер тоже работает.

Журнал CSV и картинки графиков пишутся в `data/` и в репозиторий не входят.

## Как ищется стена

1. **Монеты, раз в час.** USDT-пары с оборотом выше 200 000 USDT по недавним часовикам и медианой True Range % выше 2%. В работу идут топ-50 по волатильности.
2. **Стены, раз в 5 минут.** Уровень бида или аска больше 50 000 USDT и не меньше 3× медианы 5-минутного объёма в USDT.
3. **Жизнь стены, раз в минуту.** Проверка, что уровень ещё в стакане; учёт касания, доли разбора сделками, снятия и отскока относительно спота и фьючерса.

Пороги лежат в `config/params.py`.

## API

| Маршрут | Назначение |
|---|---|
| `GET /` | сайт |
| `GET /api/densities` | живые стены |
| `GET /api/status` | состояние сканера |
| `GET /api/outcomes` | журнал |
| `POST /api/start` `POST /api/stop` | запуск и остановка цикла |
| `GET /api/health` | проверка, что процесс жив |
